# 每日作业客户端

班级作业管理工具：编辑作业 / 公告 / 演讲提醒 → 教室电脑全屏放映 → 自动生成家庭作业图片发家长群。
单个 exe，无需安装，适合放在 U 盘里在教室电脑上直接双击使用。

## 快速开始

双击 `每日作业.exe` 即可。首次启动会在 exe 同级创建 `每日作业数据/` 目录存放数据。

## 目录与文件

| 位置 | 说明 |
|---|---|
| `每日作业.exe` | 程序本体 |
| `每日作业配置.ini` | 数据目录指针（一般不用手动改） |
| `每日作业数据/data.json` | 全部数据（天数、作业、公告、课表、设置） |
| `每日作业数据/backups/` | 自动备份（最近 30 份 + 每天一份），主文件损坏时自动恢复 |
| `家庭作业_YYYY-MM-DD.png` | 自动生成的家庭作业图片（每天只保留最新一张） |

## 每天的使用流程

1. **早上**：8:00 前打开软件自动进入"要交"模式——显示昨天勾了"明天交"的作业（日期/课表/公告仍是今天的），按 `F5` 全屏放映。
2. **白天**：在编辑页按当天课表填好各学科作业（空行不显示），勾选"明天交"；填演讲提醒（学科来自明天课表）；需要时发公告。
3. **下午/放学**：停止修改约 1 分钟后，软件自动生成 `家庭作业_*.png` 到 exe 同级目录（或随时按 `Ctrl+S` 立即生成），把图片发到家长群。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `F5` | 进入 / 退出全屏放映 |
| `Esc` | 放映中退出 |
| `←` / `→` | 翻页（焦点不在文本框时） |
| `Ctrl+T` | 切换"要交 / 全部"显示 |
| `Ctrl+K` | 本周课表总览（调课红色标注） |
| `Ctrl+,` | 设置 |
| `Ctrl+S` | 立即保存并生成图片 |
| `Ctrl+D` | 新增日期（调休补课） |

## 常见问题

**U 盘怎么安全拔出？** 软件只在保存时写盘（修改后 1 秒自动保存，窗口关闭时也会保存）。确认右下角没有"未保存修改"提示，关闭程序后再拔 U 盘。

**数据损坏 / 误删了怎么办？** 软件启动时若发现 data.json 损坏，会自动从 `每日作业数据/backups/` 里最新的可用备份恢复，并在顶部提示。

**换电脑 / 换 U 盘怎么办？** 把整个文件夹（exe + `每日作业数据/` + ini）一起拷走即可。也可以在 设置 → 数据目录 里更换存储位置（会自动复制全部数据并校验）。

**调休补课怎么录？** 工具栏"新增日期"，选择日期和"按周几的课"，该天的课表会整体标红显示；这天的作业/演讲建议行也会按该课表生成。

**演讲提醒忘了填？** 放映画面会在演讲板块位置显示红色大字警告"演讲提醒未填写！"。

## 开发者

```bash
cargo build --release   # 产出 target/release/homework-client.exe
cargo test              # 运行单元测试
homework-client --selftest  # 无窗口自检：保存/加载/导出 PNG
```
