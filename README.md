# 每日作业客户端

班级「每日作业」桌面客户端：编辑当天的作业、公告、演讲提醒、课表调课，一键全屏放映给全班查看，并自动生成今天的家庭作业图片用于发群。

替代原来「每周复制模版 PPT、奇偶页手动切换」的流程：**每天只有一页**，日期自动填，课表自动带，公告自动跨天管理。

## 运行

双击 `每日作业.exe` 即可（单文件，免安装，可直接放在 U 盘里运行）。

> 依赖系统 WebView2 运行时：Windows 11 和最新版 Windows 10 均自带。若教室电脑打不开（提示缺少 WebView2），安装一次「Microsoft Edge WebView2 Evergreen 离线包」即可，之后永久可用。

## 一天的典型使用

1. **早上 8:00 前**打开：自动进入「仅要交」模式——日期/课表/公告是今天的，作业列表显示的是**上一上学日勾选了「明天交」的作业**。直接按 `F5` 放映。
2. **8:00 后**打开：自动定位到今天、显示全部。编辑作业（学科已按今天课表预填）、演讲提醒（按明天课表预填）、公告，按 `F5` 放映。
3. 修改会自动保存；修改后隔一段时间（默认 60 秒，可在设置中改）自动生成 `家庭作业_今天日期.png` 到 exe 同目录，直插手机发群即可。旧日期的图片自动清理。

## 功能一览

- **作业**：学科按当天课表自动预填（英语自动拆 英语A/英语B），可添加其他学科；留空不显示；每条可勾选「明天交」（放映中橙色标注）。
- **公告**：分条目管理，勾选完成后放映不再显示、可取消；新的一天自动把之前的公告标记完成；切换历史日期时自动还原当天的公告可见状态。
- **演讲提醒**：按明天课表预填学科，填学号（同学科可多个，空格分隔）；完全未填写时放映和编辑页都有醒目的 ⚠ 提醒。
- **课表**：右侧当日 9 节课快捷修改，调课自动标红、改回自动取消；设置里/课表总览中可整体修改周课表模版；调休日可「新增天数」并指定上周几的课。
- **课表总览**（`Ctrl+K`）：一周 7 天 × 9 节全览，本周调课红色标注。
- **放映**：`F5` 进入全屏放映（锁定页面，不能误触切换），`F5` 或 `Esc` 退出。英语A/英语B 合占一个编号、分两行显示。
- **自动定位**：每天首次打开自动定位；运行中跨天/跨过早晨分界线（默认 8:00）自动重新定位。

## 快捷键

| 按键 | 编辑页 | 放映页 |
| --- | --- | --- |
| `F5` | 进入放映 | 退出放映 |
| `Esc` | — | 退出放映 |
| `←` / `→` | 切换上一天/下一天 | （禁用） |
| `Ctrl+T` | 回到今天（自动定位） | — |
| `Ctrl+K` | 课表总览 | — |
| `Ctrl+D` | 立即生成家庭作业图片 | — |
| `Ctrl+S` | 立即保存 | — |
| `Ctrl+,` | 设置 | — |

## 数据与安全

- 数据默认保存在 exe 同级的 `每日作业数据/data.json`；exe 同级 `每日作业配置.ini` 记录数据目录位置。
- 设置中可更换数据目录：自动复制全部数据并校验通过后才切换，旧目录保留不删。
- 每次保存先写入临时文件再原子替换，并自动滚动备份到 `每日作业数据/backups/`（保留最近 30 份，同一天只留最新）；主文件损坏时自动从备份恢复并提示。
- 所有修改 1 秒内自动落盘；关闭窗口时也会保存。

## 从源码构建

```bash
npm install
npm run tauri build        # 产物：src-tauri/target/release/homework-client.exe
cp src-tauri/target/release/homework-client.exe 每日作业.exe
```

开发与测试：

```bash
npm run tauri dev          # 开发模式（热更新）
cd src-tauri && cargo test # 后端单元测试（23 个）
```
