# 每日作业客户端

班级「每日作业」桌面客户端：编辑当天的作业、公告、演讲提醒、课表调课，一键全屏放映给全班查看，并自动生成今天的家庭作业图片用于发群。

替代原来「每周复制模版 PPT、奇偶页手动切换」的流程：**每天只有一页**，日期自动填，课表自动带，公告自动跨天管理。

## macOS 原生版（SwiftUI）

同一套数据与行为规则的 macOS 原生重写，源码在 `macos/`：

```bash
cd macos && ./scripts/build-app.sh && open build/每日作业.app
```

- 界面按 macOS 习惯重做（侧边栏 / 统一工具栏 / 原生控件 / SF Symbols / 浅色默认外观）。
- 放映画面按 1920×1080 设计稿等比缩放绘制，屏幕所见即导出 PNG（`ImageRenderer`，2 倍像素密度）。
- 新增**系统日历节假日**：读取「中国大陆节假日」订阅日历，放假当天放映显示「国庆快乐 / 周末休息」
  并跳过作业；日历标注的调休上课日会提前提醒新增这一天并确认是否调课。
- 数据文件与原版完全一致，两个版本可互读；详见 `macos/README.md`。

## 运行（Windows）

双击 `每日作业.exe` 即可（单文件，免安装，可直接放在 U 盘里运行）。

> 依赖系统 WebView2 运行时：Windows 11 和最新版 Windows 10 均自带。若教室电脑打不开（提示缺少 WebView2），安装一次「Microsoft Edge WebView2 Evergreen 离线包」即可，之后永久可用。

窗口启动即最大化（非全屏时的默认还原尺寸为 1280×800），按 `F5` 进入全屏放映。若替换 exe 后任务栏或资源管理器的图标仍显示旧的，是 Windows 图标缓存所致，执行一次 `ie4uinit.exe -show` 或注销重登即可。

## 一天的典型使用

1. **早上 8:00 前**打开：自动切到**上一上学日**这一天 + 「仅要交」——画面上的日期、星期、课表、公告都是今天的，作业列表显示的是上一上学日勾了「明天交」的那些。直接按 `F5` 放映。
2. **8:00 后**打开：自动切到今天 + 「全部」，显示今天的作业。编辑作业（学科按今天课表预填）、演讲提醒（按下一上学日课表预填）、公告，按 `F5` 放映。
3. 修改会自动保存；修改后隔一段时间（默认 60 秒，可在设置中改）自动生成 `家庭作业_今天日期.png` 到 exe 同目录，直插手机发群即可。旧日期的图片自动清理。
   自动出图固定是「今天 + 全部」；按 `Ctrl+D`（或工具栏「出图」）则是**导出你当前正在看的那一天**（含「仅要交」过滤），文件名用你选中的那一天——早自习想给群里发昨天的作业，就切到那一天再出图。

> **「全部 / 仅要交」的日期含义**：页面固定是「作业所属的那一天」（编辑页正在编辑的就是它）。选「全部」显示这一天的日期与全部作业；选「仅要交」显示这一天的**下一上学日**日期（也就是要交的那天）和其中勾了「明天交」的作业。切换模式不会换天，正在编辑的内容不会丢。上一/下一上学日按上学日计算：周五的下一日是周一；有调休（比如周日上课）时 周五→周日、周日→周一。

## 功能一览

- **作业**：学科按当天课表自动预填（英语自动拆 英语A/英语B），可添加其他学科；**一个学科可加多条作业**（学科行末的「＋」），每条单独勾「明天交」（放映时该条后面带橙色胶囊标签）；留空的不显示。放映时同一学科的多条在一行内用序号分隔、自动换行，**只有一条时不显示序号**。
- **公告**：**全局一份列表，所有日期看到的是同一份**；分条目管理，勾选完成后放映不再显示、可取消；公告不会自动消失，需要手动勾完成或删除。
- **演讲提醒**：按明天课表预填学科，填学号（同学科可多个，空格分隔）；完全未填写时放映和编辑页都有醒目的 ⚠ 提醒。
- **课表**：右侧当日 9 节课快捷修改，调课自动标红、改回自动取消；周课表模版在「课表总览」里整体修改；调休日与「上哪天的课」在「设置 → 天数管理」里维护。
- **课表总览**（`Ctrl+K`）：整页显示一周 7 天 × 9 节全览，今天整列高亮、本周调课红色标注，可直接编辑并保存周课表模版。
- **设置**（`Ctrl+,`）：整页显示，含数据目录、出图间隔、早晨分界线、放映是否显示班徽，以及天数管理（新增天数、删除天数、每天的调休来源）。
- **放映**：`F5` 进入全屏放映（锁定页面，不能误触切换），`F5` 或 `Esc` 退出；**右键**弹出菜单，可切换「全部 / 仅要交」、立即生成作业图片、退出放映。顶部标题带显示日期与星期；左侧家庭作业（编号徽章 + 固定标签列，同一学科多条用序号分隔并自动换行，只有一条时不显示序号，勾了「明天交」的条目紧跟橙色胶囊标签），右侧两栏课表 + 演讲提醒；**没有公告时公告条整条隐藏**，把版面让给作业。英语A/英语B 合占一个编号、分两行显示。
- **自动定位**：每天首次打开自动定位；运行中跨天/跨过早晨分界线（默认 8:00）自动重新定位。

## 快捷键

编辑时基本不用碰鼠标：`Alt+1~4` 在四个区之间跳，`回车` 在当前位置新建下一条，`Ctrl+回车` 标记当前条目。

| 按键 | 编辑页 | 放映页 |
| --- | --- | --- |
| `Alt`+`1`/`2`/`3`/`4` | 跳到 公告 / 作业 / 演讲提醒 / 课表 | — |
| `Enter` | 新建下一条（课表为下一节） | — |
| `Ctrl`+`Enter` | 标记当前条目（明天交 / 公告完成） | — |
| `Alt`+`↑`/`↓` | 在条目之间上下切换 | — |
| `←` / `→` | 切换上一天 / 下一天 | （禁用） |
| `F5` | 进入放映 | 退出放映 |
| `Esc` | 设置/课表总览里返回编辑页 | 退出放映 |
| `Ctrl+T` | 回到今天（自动定位） | — |
| `Ctrl+K` | 课表总览 | — |
| `Ctrl+D` | 立即生成家庭作业图片 | — |
| `Ctrl+S` | 立即保存 | — |
| `Ctrl+,` | 设置 | — |

## 数据与安全

- 数据默认保存在 exe 同级的 `每日作业数据/data.json`；exe 同级 `每日作业配置.ini` 记录数据目录位置。
- 设置中可更换数据目录：自动复制全部数据并校验通过后才切换，旧目录保留不删。
- 每次保存先写入临时文件再原子替换，并自动滚动备份到 `每日作业数据/backups/`（保留最近 30 份，同一天只留最新）；主文件损坏时自动从备份恢复并提示。
- 所有修改 1 秒内自动落盘；关闭窗口时也会保存。
